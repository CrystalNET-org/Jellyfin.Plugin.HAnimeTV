Library

Where the library's files go: a .strm file (the episode's stream link) and an NFO file (its metadata) per episode. Empty means the folder hanime.tv in Jellyfin's data directory (). Use an empty folder: the plugin replaces everything in it.
Creates a shows library for the folder if there is none, which reads only the plugin's metadata and never extracts trickplay or chapter images from the streams. To change it later, use Dashboard → Libraries.
The address in the stream links of the .strm files, e.g. https://jellyfin.example.com. Jellyfin's ffmpeg and every ffmpeg worker start streams from it, and browsers play these links themselves, so use the address your clients open Jellyfin with, as long as all ffmpeg workers reach it too. In Kubernetes, that is the ingress address: Jellyfin's own guess is the pod's IP, which changes and is not reachable from outside the cluster. Filled in with this page's address when empty; save to use it.
