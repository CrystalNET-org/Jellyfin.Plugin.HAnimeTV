Streams & access

The address in the stream links of the .strm files and channel videos, e.g. https://jellyfin.example.com. Jellyfin's ffmpeg and every ffmpeg worker start streams from it, and browsers play these links themselves, so use the address your clients open Jellyfin with, as long as all ffmpeg workers reach it too. In Kubernetes, that is the ingress address: Jellyfin's own guess is the pod's IP, which changes and is not reachable from outside the cluster. Filled in with this page's address when empty; save to use it.
Recommended. The channel and library access of every user's policy (Dashboard → Users → Access) follows the providers' user selections, so Jellyfin itself hides their channels, libraries and videos from the others. A user who had access to all channels or libraries and is not selected keeps access to every other one, now listed one by one: tick Enable access to all again there and the plugin takes the provider out again within 15 minutes (scheduled task Enforce Adult Media access). Without it, set the users' access yourself.
